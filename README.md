# AI Resume Analyzer 🚀

An AI-powered Resume Analyzer built using React, TypeScript, Tailwind CSS, and Puter.js. This application helps users upload resumes, analyze ATS compatibility, and receive smart AI-based resume feedback for job applications.

## ✨ Features

- Upload and analyze resumes
- ATS-style resume scoring
- AI-powered resume feedback
- Resume preview support
- Clean and responsive UI
- Authentication using Puter.js
- Resume history tracking

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Puter.js
- React Router
- Zustand

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/avnish-creator/ai-resume-analyzer-avnish.git
```

Go to project folder:

```bash
cd ai-resume-analyzer-avnish
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
